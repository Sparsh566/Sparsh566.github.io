My Personal Static Website Hosted with GitHub Pages

This repository contains the source code for my static website hosted using GitHub Pages.
The site is publicly accessible at:

👉 https://Sparsh566.github.io

📁 Project Structure
├── index.html      # Main webpage
├── style.css       # Website styling
└── script.js       # JavaScript functionality

🚀 Deployment

This website is automatically deployed using GitHub Pages.

Whenever I push a new commit to the main branch, the website updates within a few seconds.

🛠️ Tech Used

HTML5

CSS3

JavaScript

GitHub Pages for free hosting

📌 How to Update the Site

Make changes to your local files (index.html, style.css, or script.js).

Commit changes in GitHub Desktop.

Push to the main branch.

Website updates automatically.

🎯 Purpose

This repository is part of my web development learning tasks and showcases a simple static website deployment workflow.
